# 구글 포토 사진 연도별 정리 방법

## 1단계: 구글 테이크아웃으로 사진 내려받기
1. https://takeout.google.com 에 접속합니다.
2. "모두 선택 해제"를 누른 뒤 **Google 포토**만 선택합니다.
3. 내보내기 형식은 zip, 파일 크기는 원하는 대로(예: 50GB) 고릅니다.
4. 준비 완료 메일이 오면 zip 파일을 모두 내려받아 **한 폴더에 압축을 풉니다.**

## 2단계: 정리 스크립트 실행 (PC에 Python 3 필요)
```bash
python3 sort_photos_by_year.py "테이크아웃_폴더" "정리된_사진" --dry-run   # 미리보기
python3 sort_photos_by_year.py "테이크아웃_폴더" "정리된_사진"             # 실제 복사
```
- 결과: `정리된_사진/2019년`, `2020년`, … `날짜미상` 폴더가 생깁니다.
- 기본은 **복사**라 원본이 남습니다. 공간이 부족하면 `--move`로 이동하세요.
- (선택) `pip install Pillow`를 하면 JSON이 없는 사진도 EXIF 촬영일로 분류합니다.

## 촬영 연도 판단 순서
1. 테이크아웃 JSON의 `photoTakenTime` → 2. 사진 EXIF 촬영일 → 3. 파일 이름 속 날짜 → 4. `날짜미상`

## 특정 연도를 월별로 정리하기 (예: 2020년)
```bash
python3 sort_photos_by_year.py "테이크아웃_폴더" "정리된_사진" --year 2020 --by-month --dry-run   # 미리보기
python3 sort_photos_by_year.py "테이크아웃_폴더" "정리된_사진" --year 2020 --by-month             # 실제 복사
```
- 결과: `정리된_사진/2020년/01월`, `02월`, … `12월`
- `--year`를 빼고 `--by-month`만 쓰면 모든 연도를 연도/월 폴더로 정리합니다.
- 촬영 시각은 한국 시간(UTC+9) 기준입니다. 해외 사진은 `--utc-offset`으로 시간대를 바꿀 수 있습니다.
